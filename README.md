## Featured Projects

### Bible Research — open-source organization
A dedicated Bible reading & study platform maintained under the
[Bible-Research](https://github.com/Bible-Research) organization.

- **[bible_research](https://github.com/Bible-Research/bible_research)**
  — Django 5.2 + DRF REST API deployed on Google App Engine. Routes
  passage/audio requests across multiple providers (DBT, ESV API,
  SWORD modules, API.Bible) via a `fileset_id` key, with a stable
  `error`/`error_code` failure contract.
  `Python` `Django` `DRF` `PostgreSQL` `GCP` `Terraform`
- **[reactive-bible](https://github.com/Bible-Research/reactive-bible)**
  — React 18 + TypeScript SPA (Vite, Mantine, Zustand, TipTap) on
  Vercel, wrapped for Android via Capacitor. Features notes, tags,
  comments, audio Bible and a 3-tier localStorage cache.
  `React` `TypeScript` `Vite` `Zustand` `Capacitor`

### [Geo Clash](https://github.com/Ted-Rose/geo-clash)
Mobile-first, real-time multiplayer territory game on OpenStreetMap:
stand in a 5x5 m cell to claim it, swing your phone to fire arrows.
Authoritative Socket.io server with per-room isolation and
server-committed projectile telemetry.
`React` `Leaflet` `TailwindCSS` `Node.js` `Socket.io`

### [Responzilla](https://github.com/Ted-Rose/responzilla)
**Built during a hackathon.** AI tool that detects when incoming
Slack/Jira questions were already answered and links the original
threads. Slack + Confluence scraping, Gemini embeddings and Qdrant
vector search behind a socket-mode Slack bot.
`Python` `Gemini` `Qdrant` `Slack API` `Docker`

### [Finance Consultant](https://github.com/Ted-Rose/finance-consultant)
**Built during a hackathon.** Private AI financial assistant you talk
to: voice input via SpeechRecognition, a self-hosted Ollama LLM for
answers and gTTS audio replies — no data leaves your machine.
`Python` `Django` `Ollama` `SpeechRecognition` `gTTS`

### [Industry Analyser](https://github.com/Ted-Rose/industry-analyser)
Django platform scraping and analysing Latvian classified-ad portals
(rentals, sales, job vacancies). Modular scraper architecture with
shared base classes, management commands and Terraform-managed GCP
infrastructure.
`Python` `Django` `Web scraping` `Terraform` `GCP`

### [Django Apps](https://github.com/Ted-Rose/django-apps)
Collection of standalone Django mini-apps — including Gmail-to-audio,
which fetches your inbox and reads it aloud. Deployed via
Vercel/PythonAnywhere with GitHub Actions pipelines.
`Python` `Django` `REST API` `CI/CD`
